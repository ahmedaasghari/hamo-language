# Hamo Phonology & Sound System

Hamo limits its inventory to sounds found across almost all spoken human languages, eliminating complex tongue movements or harsh consonant clusters.

## 1. Vowels (5 Pure Vowels)

| Symbol | IPA | English Sound | Semantic Meaning / Direction |
| :--- | :--- | :--- | :--- |
| **a** | `/a/` | "ah" (*father*) | Expansion, outward, open, active |
| **i** | `/i/` | "ee" (*see*) | Focus, inward, detail, precision |
| **u** | `/u/` | "oo" (*moon*) | Depth, grounding, foundation |
| **e** | `/e/` | "eh" (*bed*) | Transition, process, flow |
| **o** | `/o/` | "oh" (*go*) | Completion, whole, boundary, static |

## 2. Consonants (10 Universal Consonants)

| Symbol | IPA | Domain / Primary Category |
| :--- | :--- | :--- |
| **m** | `/m/` | **Internal / Mind:** Consciousness, emotion, thought |
| **n** | `/n/` | **External / World:** Nature, environment, physical presence |
| **p** | `/p/` | **Force / Action:** Creation, power, initiation |
| **t** | `/t/` | **Time / Sequence:** Duration, cause-effect, history |
| **k** | `/k/` | **Structure / Order:** Logic, system, point |
| **s** | `/s/` | **Space / Motion:** Travel, atmosphere, distance |
| **l** | `/l/` | **Relation / Link:** Connection, social bonds, trade |
| **w** | `/w/` | **Energy / Vitality:** Light, heat, signal, wave |
| **h** | `/h/` | **Life / Spirit:** Breath, organic state, existence |
| **r** | `/r/` | **Cycle / Rhythm:** Repeat, transformation, loop |

## 3. Syllable Rules & Stress
* **Syllable Structure:** Strictly C1V1C2V2 for compound words, CV for pronouns/particles.
* **Stress:** Always placed predictably on the **first syllable** (e.g., *HA-wa*, *PE-ko*).
